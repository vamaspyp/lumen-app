## Capacidades semilla propuestas para materialización A63

No son una taxonomía total. Son cobertura semilla suficiente para demostrar el modelo:

1. **Discernimiento** — pregunta/reflexión + herramienta/decisión + conversación/persona + revisión posterior.
2. **Regulación / volver a un estado habitable** — práctica breve + audio/off-screen + acción real + apoyo humano cuando corresponda.
3. **Agencia** — reflexión + acción concreta + herramienta + persona/mentor + transferencia a contexto real.
4. **Conexión** — reflexión + conversación 1:1 + círculo + acción relacional + Derrame.

Cada Capacidad debe decir humanamente qué puede ayudar a cultivar, nunca cuánto “tiene” la persona. Ninguna muestra nivel, porcentaje, progreso, ranking o diagnóstico.

## Expresiones nuevas necesarias

### A. Capacidad como lente opcional
Desde Fuente, Territorio o un Faro puede emerger: “Parece que acá querés cultivar discernimiento”. Debe poder corregirse, ignorarse o reformularse. La persona también puede explorar una Capacidad deliberadamente.

### B. Constelación viva
Una escena muestra varias Posibilidades complementarias alrededor de una Capacidad: comprender, practicar, aplicar, conversar, reflexionar/integrar. Sin orden, checklist ni progreso. Relaciones: “otra forma”, “más breve”, “llevar a la vida”, “con alguien”, “volver sobre lo vivido”.

### C. Cultivar
Después de una experiencia útil: repetir / variar / aplicar en otro contexto / profundizar / conversar / descansar / dejarlo. Es movimiento, no fase obligatoria.

### D. Transferencia
“Esto te sirvió caminando. ¿Querés probar una versión mínima antes de esa conversación?” El retorno de transferencia se conserva distinto del retorno puntual.

### E. Apropiación y retiro
“Ya sabés volver a esto por tu cuenta. Puedo dejar de sugerirlo.” Acciones: dejarlo en Repertorio / no recordarlo / usarlo en otro contexto / compartirlo si quiere.

### F. Continuidad acumulativa
Territorio debe poder mostrar relaciones significativas: Faro ↔ Capacidad ↔ Posibilidades vividas ↔ retornos ↔ Repertorio, sin convertirlo en timeline/productividad.

### G. Cobertura honesta
Cada Capacidad semilla declara suficiente diversidad real. Fuera de cobertura, NO_MATCH sigue siendo preferible a una constelación falsa.

## Gate funcional de la siguiente materialización

La capa queda funcionalmente alineada cuando puede demostrarse, sin explicación externa:

`Momento → hipótesis de Capacidad/contexto → constelación → Posibilidad → Experiencia → Retorno → Cultivar → Repertorio/continuidad → regreso posterior → recuperar/repetir/variar/transferir → nuevo Retorno → apropiación prudente → menor protagonismo de LUMI`.

Además debe poder abandonarse en cualquier punto, cambiar de Faro, corregir la hipótesis de Capacidad, elegir una persona en lugar de contenido, no responder al retorno, y recibir NO_MATCH si la cobertura no alcanza.

## No hacer

No crear pantalla de “mis capacidades”, radar, score, niveles, progreso, diagnóstico, curso, currículum, árbol de habilidades, organigrama visible ni secuencia obligatoria. No convertir constelaciones en playlists. No hacer de Cultivo un nuevo órgano. No sacrificar la naturaleza V15/V16 del mismo Experience & Sensation Field.
