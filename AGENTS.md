# VA+LUMEN · Agent Bootstrap

Antes de analizar o ejecutar cualquier trabajo material en este repositorio:

1. Leer `governance/CONDUCTION_GATE.md`.
2. Resolver en la POV vigente el FOCO, ACTO/DoD y autoridades aplicables.
3. Verificar que `governance/conduction-context.json` refleja ese ACTO real.
4. Inspeccionar código/DB/infra reales antes de ajustar.
5. Si la POV, la autoridad o la realidad material no pueden resolverse, FAIL CLOSED: detener diseño/mutación y escalar con evidencia.

No usar memoria de conversación, documentos históricos ni implementación como sustituto de autoridad vigente.
